# Book Recommender System

A Machine Learning based Book Recommender System that suggests similar books based on user selection.

Live Demo: https://zainxhaikh.pythonanywhere.com/recommend

## Tech Stack
- Python
- Pandas, NumPy, Scikit-learn
- Flask
- HTML, CSS

## How it Works
- Uses Collaborative Filtering to find similar books
- Dataset contains Books, Users, and Ratings
- Popularity based + Collaborative Filtering approach used
- When user selects a book, system recommends top 5 similar books with cover images

## Features
- Search and select any book
- Get top 5 recommended books instantly
- Live deployed web app

## How to Run Locally
1. Clone this repo
2. Install requirements: `pip install -r requirements.txt`
3. Run: `python app.py`
4. Open browser: `http://127.0.0.1:5000`
